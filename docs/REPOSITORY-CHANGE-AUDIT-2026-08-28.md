# Repository Change Audit — 2026-08-28

## Change control
Existing repository content is the protected baseline. A difference from a working copy or earlier document is not permission to overwrite, delete, move, refactor, or otherwise alter it.

## Traceability
Material changes must be traceable to the requested scope, the exact Git diff, and verification evidence. Commit titles alone are not sufficient evidence of authorisation.

## Verification
Claims such as fixed, complete, secure, production-ready, or verified require corresponding evidence. Unknown historical intent must remain marked unknown rather than inferred.

## Historical integrity
Git history must not be rewritten to conceal corrections. Corrections should be separate, explicit commits.
